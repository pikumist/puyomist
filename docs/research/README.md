# 調査記録

探索アルゴリズムの設計を決めるために行った調査の記録です。

仕組みそのものの解説は [ぷよ塗り探索の仕組み](../paint-search-overview.md) にあります。

**これは仕様書ではありません。** 「何を試して、何を採用し、何を却下したか」と、その判断根拠になった
実測値を残すためのものです。現在の実装の正確な姿はコードを見てください。ここに書かれた却下案や
中間の数値は、当時の測定条件でのものです。

共通の方針は **推測するな、計測せよ**。採用・却下はすべて実測に基づいています。
